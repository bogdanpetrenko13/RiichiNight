# Character art

One folder per character id from `src/game/characters.ts`:

```
<id>/portrait.webp            square table portrait (~512px)
<id>/emotions/neutral.webp    also: happy, confident, surprised, troubled
<id>/reward/stage1.webp       reward scene for stage 1 … stage<stages-1>
```

Missing files are fine: the game shows a generated placeholder.
All characters must be adults (18+) and drawn so they clearly read as adults.
