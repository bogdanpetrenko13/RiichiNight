# Character art credits

The current heroine portraits and reward scenes are **placeholder art** built
by `scripts/import-renpy-art.py` from the demo games shipped with the Ren'Py
visual novel engine (https://github.com/renpy/renpy, commit in
`renpy.version`):

| Heroine | Source sprite |
|---|---|
| Hikari | Eileen — `tutorial/game/images/eileen *.png` |
| Rin | Lucy — `tutorial/game/images/lucy *.png` |
| Mai | Sylvie, green outfit — `the_question/game/images/sylvie green *.png` |
| Yuzu | Sylvie, blue outfit — `the_question/game/images/sylvie blue *.png` |

Scene backgrounds: `the_question/game/images/bg *.jpg`.
